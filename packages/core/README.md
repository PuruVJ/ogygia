# @ogygia/core

The core of [ogygia](https://ogygia.puruvj.dev): SSR islands for SvelteKit, no Kit patches.

Apps install [`ogygia`](https://www.npmjs.com/package/ogygia), which re-exports this package subpath for
subpath. Plugin packages (`@ogygia/flags`, `@ogygia/devtools`, …) build on `@ogygia/core` and its
`@ogygia/core/plugin` door.

Docs: [ogygia.puruvj.dev](https://ogygia.puruvj.dev)
