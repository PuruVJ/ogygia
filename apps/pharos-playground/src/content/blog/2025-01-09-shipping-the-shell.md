The blog shell is here: `BlogShell` (the chrome), `BlogList` (the dated index), and `BlogPost` (a single post). Same tokens as the docs shell, a centered single-column read, and prev/next by date.

It reads the `PostFields` (`date`, `author`, `tags`) the blog genre already defined — so a blog is now three components over a dated collection.
