**Breaking:** features move into plugin packages, each a Vite plugin listed beside `ogygia()` and before `sveltekit()` (`plugins: [ogygia(), flags(), sveltekit()]`; out of order, or without `ogygia()`, the build says so): flags (`@ogygia/flags`, was `ogygia/flag`), frozen pages (`@ogygia/freeze`, was `ogygia/freeze` and `ogygia({ freeze })`), fragment federation (`@ogygia/federation`, was `ogygia/federation`; `mount` moved from `ogygia/router`) and content (`@ogygia/content`, was `ogygia/content*` and `ogygia({ content })`; `ogygia/content/server` is `@ogygia/content/server`, and the svelte config's `ogygia.preprocess()` / `ogygia.extensions()` are `preprocess()` / `extensions()` from `@ogygia/content/vite`), each with its factory from `<package>/vite`. The devtools dock and the profiler move to `@ogygia/devtools`: `ogygia({ devtools, profiler })` becomes `devtools({ dock, profiler })`, `ogygia/profiler*` imports become `@ogygia/devtools/profiler*` (`@ogygia/devtools/profiler`, `/profiler/client`, `/profiler/storage`, `/profiler/storage/sqlite|redis|postgres`), and the event layer `ogygia/devtools` exported is `ogygia/events` (with `ogygia/insights` beside it). `ogygia/testing` is `@ogygia/testing`. The server router is `@ogygia/router` (was `ogygia/router`; list `router()` from `@ogygia/router/vite` so its pages' CSS links — dev warns when a page renders without it), and its typed fetch client `ogygia/router/client` is `@ogygia/router/api` (`POST(schema, …)` endpoints now type-check, and `$infer` carries their verbs). An endpoint handler's `c.params` is now typed strictly by its table key, at the top level, inside `layout()` tables and behind `when()`, and its return type reaches `api()`; `GET<'/p'>(fn)` is gone (a handler written outside its table checks with `satisfies Handler<'/p'>`). A plugin is made with `definePlugin({ name, server, client, options, build })` from `ogygia/vite`, which returns a Vite plugin; its server and browser halves are named by location (`server: import.meta.resolve('./server.ts')`) instead of found by package export name. The command line lives in `@ogygia/cli` (`npx ogygia …` keeps working: `ogygia`'s bin runs it). `ogygia` is now a thin package over `@ogygia/core`; plugins depend on `@ogygia/core`. `ogygia()`'s region options sit at its root: `regions.visible`, `regions.presets`, `regions.ttl` and `regions.maxPageAge` are `visible`, `presets`, `ttl` and `maxPageAge`. `@ogygia/tsdown-plugin-svelte` turns a component's relative `./x.ts` imports into `./x.js` in the shipped component and its types, so sources can import with real extensions. Fixed: a Kit-hydrated (`csr = true`) page could link the stylesheets of every region in the app, depending on how the bundler grouped the server build (newer rolldown, under vite 8.3, did).
